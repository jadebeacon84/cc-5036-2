# 试验室布置三维编辑器

基于 Three.js 的试验室设备布局编辑器。用户通过三维轴向操纵器（gizmo）直接在场景中
移动、旋转、缩放自制参数化设备模型，支持世界/局部坐标模式、透视/正交投影，
并可将布局保存为 JSON。

## 运行

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 生产构建
npm test           # 37 个 Node 单元/集成测试（纯数学 + Three 变换，含多父节点多选回归）
npm run test:browser   # 真实浏览器冒烟测试（需先装浏览器系统库，见下）
```

浏览器冒烟测试需要 Chromium 运行库：

```bash
npx playwright install --with-deps chromium
npm run test:browser
```

在无 root、缺少 `libnspr4` 等系统库的环境中，该脚本会打印原因并以 0 状态码跳过；
核心求交与变换逻辑由 `npm test` 在 Node 下完整覆盖。

## 交互

- 左键拖动操纵器：单轴箭头/方块 = 单轴约束，平面块 = 双轴平面，彩色环 = 绕轴旋转，
  中心白块 = 等比缩放
- 空白处拖动 = 旋转视角，滚轮 = 缩放，单击设备 = 选中，
  **Shift+点击设备或左侧列表项 = 多选/取消多选**
- 多选后一次拖动同时变换所有选中对象：世界平移/旋转意图只对主对象（操纵器锚点）
  计算一次，再按**每个对象各自的父节点世界逆矩阵**分别换算回局部；
  `Esc` 或 `pointercancel` 取消拖动并逐对象恢复原值，`Ctrl+Z`（或工具栏“撤销”）
  按提交记录回滚，撤销栈最多保留 50 步
- 快捷键：`W` 移动、`E` 旋转、`R` 缩放、`Q` 世界/局部空间、`P` 投影切换、
  `Esc` 取消拖动、`Ctrl+Z` 撤销、`Del` 删除
- 右侧检查器只读展示实际世界位置、姿态（欧拉角+四元数）、三轴缩放与当前约束轴；
  不提供数值输入框，所有变换必须通过直接三维交互完成

## 稳定性设计（对应关键需求）

### 1. 求交稳定与明确退化策略

射线-轴求交（`src/editor/math3d.js:rayAxis`）使用最小二乘最近点解，
分母为 `1 - (dir·axis)²`。当视线与轴夹角的 sin² 小于 `1e-8`（约 0.0057°）时，
**不执行除法**，显式返回 `parallel: true`，上层切换到退化策略：

- 单轴平移/缩放：改用**包含该操纵轴**、且最朝向相机的坐标平面
  （法向取另外两轴中与视线点积最大者），取两交点在轴上的分量。
  若误用垂直于视线的平面，轴上运动会被完全投影掉（这是常见错误实现）。
- 双轴平移：原平面被看成一条线时，切换到最朝向相机的坐标平面。
- 旋转：环被看成一条线时，在视图平面内测有符号角，并用轴与视线的朝向修正符号。
- 所有路径对结果做 `Number.isFinite` 兜底，非法值直接丢弃，物体保持不动，绝不飞走。

### 2. 屏幕尺寸与几何尺度解耦

`gizmoWorldSize` 按相机参数独立计算操纵器世界尺度：透视下与视距成正比
（屏幕占比恒定），正交下只与可视高度相关。对象被缩放到 1000 倍或 0.001 倍，
操纵器的手感和像素大小完全不变（有测试覆盖）。

### 3. 快照基准，不累积浮点误差

每次 `beginDrag` 保存基准（局部位置/姿态/缩放、世界位置/姿态、父节点逆矩阵、
初始射线、操纵器尺度）。后续每个 `pointermove` 都从同一基准、按当前射线重新计算
绝对变换，不做增量累加。因此一次拖拽内无论经过多少事件、往返拖动多少次，
回到起始射线时变换与基准逐位一致（往返测试误差 < 1e-10）。

### 4. 层级与非均匀缩放

每台设备是独立 `Group`（旋转父节点），变换只作用于该 Group。
世界平移通过**该对象自己的**父节点世界逆矩阵映射回局部；世界旋转左乘世界姿态再换回
父局部；缩放始终沿局部轴以保留非均匀缩法语义。

多选时各对象可能挂在旋转、非均匀缩放各不相同的父节点下。`beginDrag` 为每个对象单独
快照并保存其**各自的父逆矩阵/父姿态**，拖拽意图（世界增量、世界旋转、缩放系数）只对
主对象求一次，再逐对象经各自父逆矩阵换算——既不共用某一个对象的父变换，也绝不为了
省事而清空/重置父变换。`test/multiselect.test.js` 覆盖两个不同旋转+非均匀缩放父节点、
极端父缩放 `(1000, 0.001, 3.2)`、往返还原、`Esc`/`pointercancel` 取消恢复与撤销快照。

## 测试矩阵

`test/math3d.test.js`：求交正确性、平行/近平行退化、有符号角符号、两种投影下的
恒定屏幕尺度、非有限输入回退。

`test/gizmo.test.js`：单轴/平面平移与往返还原、三种退化分支、世界/局部旋转、
单轴/等比缩放与钳制、旋转父节点+非均匀父缩放、正交投影、极大/极小模型尺度解耦、
画布四角 NDC 射线、手柄拾取过滤。

`test/multiselect.test.js`：多父节点（各自旋转+非均匀缩放）下同一世界意图逐对象
父逆换算、平面多选、`Esc`/`pointercancel` 取消逐对象恢复原值、提交快照与 `restore`
撤销、极端父缩放边界（不允许用默认值/清零遮错）、单选 API 向后兼容。

`test/browser.smoke.js`：真实 Chromium 指针事件。先扫描内核可拾取的手柄像素再拖动，
覆盖单轴/旋转/缩放、Shift 多选同拖（两对象世界位移一致）、Esc 取消恢复、Ctrl+Z 撤销、
投影/空间切换、保存 JSON 与无控制台错误。无系统库时自动跳过。

## 安全边界

本工具只解决“设备在房间几何空间内如何摆放”的问题。**几何上可摆放不构成任何真实
安装安全结论**——电气接入、承重、通风风量、防爆间距、气体管路等合规要求必须由
专业人员依据现行规范另行评估。此声明同时固定显示在界面右侧面板和导出的 JSON 中。
